# Выгода float (беспроцентный кредит)

Документ фиксирует алгоритм **накопительной** выгоды от денег, «припаркованных» на связанном с кредитной картой счёте, пока действует грейс.

Код: [`src/engine/creditFloatEngine.ts`](src/engine/creditFloatEngine.ts).  
UI: вкладка Float, виджет «Выгода float» на дашборде.

---

## 1. Модель

У каждой кредитки есть:

- **лимит** и остаток доступного лимита в чек-ине → долг = `max(0, лимит − доступно)`;
- **связанный счёт** (`linkedAccountId`) — куда фактически «лежат» деньги, пока долг не погашен;
- **грейс** в календарных месяцах (по умолчанию 3).

Выгода float — не процент банка по карте, а **доля прироста связанного счёта**, которую можно отнести к кредитным средствам (и к ранее закреплённому доходу от них).

---

## 2. Корзины капитала (накопительный эффект)

По каждой карточке в валюте связанного счёта ведётся накопитель `lockedEarnings` — уже закреплённая за кредиткой часть прироста.

Для календарного месяца считаем прирост связанного счёта `G` (без переводов) и Dietz-взвешенный капитал `W` (как в портфельном росте).

Корзины на месяц:

| Корзина | Обозначение | Формула |
|---------|-------------|---------|
| Кредитка | `C` | `max(средний долг за месяц, сумма переводов linked→карта)` |
| Проценты с кредитки | `I` | `min(lockedEarnings, max(0, W − C))` |
| База | `B` | `max(0, W − C − I)` |

`I` обрезается, если остаток/взвешенный капитал меньше накопленного locked (выводы со счёта).

---

## 3. Разложение прироста

Пусть `T = B + C + I`. Если `T > 0`:

```
baseGrowth     = G × B / T
creditGrowth   = G × C / T
interestGrowth = G × I / T
```

Выгода месяца:

```
earned = creditGrowth + interestGrowth
```

Закрепление на следующий месяц:

```
lockedEarnings += earned
```

Отрицательный прирост пропорционально уменьшает locked.

Доля кредитных средств в приросте месяца:

```
floatSharePct = earned / G   (если G ≠ 0)
```

На первом месяце при `lockedEarnings = 0` формула совпадает с прежней:
`earned = G × C / W`.

`cumulativeEarned` по карточке = `lockedEarnings` на конец периода (в валюте linked).  
В базовой валюте месячные куски конвертируются курсом на конец месяца и суммируются для виджетов.

---

## 4. Что показывается в UI

- **Итого float** — сумма закреплённой выгоды.
- По месяцам: прирост базы / кредитки / процентов с кредитки / итого float.
- Расшифровка: абсолютные суммы трёх частей, доля выгоды от кредитных средств, накопленный locked.
