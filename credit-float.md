# Выгода float (беспроцентный кредит)

Документ фиксирует алгоритм **накопительной** выгоды от денег, «припаркованных» на связанном с кредитной картой счёте, пока действует грейс.

Код: [`src/engine/creditFloatEngine.ts`](src/engine/creditFloatEngine.ts).  
UI: вкладка Float, виджет «Выгода float» на дашборде.

---

## 1. Модель

У каждой кредитки есть:

- **лимит** и остаток доступного лимита в чек-ине → долг = `max(0, лимит − доступно)`;
- **связанный счёт** (`linkedAccountId`) — куда фактически «лежат» деньги, пока долг не погашен;
- **грейс** в календарных месяцах (по умолчанию 3).

Выгода float — не процент банка по карте, а **доля прироста связанного счёта**, которую можно отнести к кредитным средствам (и к ранее закреплённому доходу от них).

---

## 2. Шаг накопления — день изменения связанного счёта

Проценты на связанном счёте начисляются почти ежедневно, поэтому закрепление float идёт **по интервалам между чек-инами**, где в снапшоте явно указан связанный счёт.

1. Берём даты чек-инов со строкой связанного счёта (по возрастанию).
2. Для каждой пары `(t₀, t₁]` считаем прирост `G` (без переводов) и Dietz-взвешенный капитал `W`.
3. В UI показываем только дни с `|G| > 0` (было изменение счёта).
4. `lockedEarnings` обновляется на **каждом** таком интервале и переносится на следующий день.

Месяц на вкладке Float — агрегат дней; месяц можно развернуть и увидеть список дней.

---

## 3. Корзины капитала

По каждой карточке в валюте связанного счёта ведётся накопитель `lockedEarnings`.

Корзины на день (интервал):

| Корзина | Обозначение | Формула |
|---------|-------------|---------|
| Кредитка | `C` | `max(средний долг на концах интервала, сумма переводов linked→карта)` |
| Проценты с кредитки | `I` | `min(lockedEarnings, max(0, W − C))` |
| База | `B` | `max(0, W − C − I)` |

`I` обрезается, если взвешенный капитал меньше накопленного locked (выводы со счёта).

---

## 4. Разложение прироста

Пусть `T = B + C + I`. Если `T > 0`:

```
baseGrowth     = G × B / T
creditGrowth   = G × C / T
interestGrowth = G × I / T
```

Выгода дня:

```
earned = creditGrowth + interestGrowth
lockedEarnings += earned
```

Отрицательный прирост пропорционально уменьшает locked.

Доля кредитных средств:

```
floatSharePct = earned / G   (если G ≠ 0)
```

`cumulativeEarned` по карточке = `lockedEarnings` на конец периода.  
В базовой валюте дневные куски конвертируются курсом на дату дня и суммируются для виджетов.

---

## 5. Что показывается в UI

- **Итого float** — сумма закреплённой выгоды.
- По месяцам: суммы прироста база / кредитка / % с кредитки / float.
- Разворот месяца → дни изменения связанного счёта. По каждому дню формулы с подставленными значениями:

```
База:        B₀ + ΔB = B₁
Кредитка:    C₀ + ΔC = C₁
Накопленный: I₀ + ΔC + ΔI = locked₁
```

Каждое число открывает расшифровку: на десктопе по наведению, на телефоне по нажатию.
