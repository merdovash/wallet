# Расчёт процента прироста

Документ фиксирует алгоритм расчёта **прироста** и **прироста %** по портфелю накоплений (фонд / вклад / инвестиции).

Код:

- [`src/lib/accountKinds.ts`](src/lib/accountKinds.ts) — какие счета входят в портфель
- [`src/engine/growthEngine.ts`](src/engine/growthEngine.ts) — потоки капитала, серия прироста
- [`src/lib/monthlyReturns.ts`](src/lib/monthlyReturns.ts) — период и помесячные %, годовые
- [`src/lib/growthFxBreakdown.ts`](src/lib/growthFxBreakdown.ts) — разложение прироста на валюту и курс

Метод процента: **Modified Dietz** (взвешивание внешних потоков по доле оставшихся дней периода).

---

## 1. Портфель роста

В расчёт входят счета видов `fund`, `deposit`, `investment` — **по виду счёта**, в том числе **архивные** (история до последней записи в чек-инах сохраняется; после неё остаток считается нулевым).

| Вид | Входит |
|-----|--------|
| `fund` (фонд / накопления) | да |
| `deposit` (вклад) | да |
| `investment` (инвестиции) | да |
| `operational` (оперативный) | нет |
| `cash` (наличка) | нет |
| `credit` (кредитка) | нет |
| `cashback` (кэшбек) | нет |

**Капитал на дату** = сумма **эффективных** остатков этих счетов (forward-fill до последней строки чек-ина, затем 0), в базовой валюте по курсу на эту дату.

Остаток на дашборде («Остаток») может включать все счета; **прирост %** (Modified Dietz) считается только по портфелю роста. **Годовых от массы** берёт тот же прирост инвестиций без пополнений, но делит на всю сумму денег.

---

## 2. Внешние потоки капитала

Потоки — это изменение капитала портфеля, которое **не является** доходностью (проценты, переоценка и т.п.).

За интервал `(t₀, t₁]` в базовой валюте учитываются **только переводы через границу портфеля**:

- из не-ростового счёта → в ростовой: **+сумма** (пополнение);
- из ростового → в не-ростовой: **−сумма** (вывод).

Переводы **между** ростовыми счетами друг друга **не** меняют капитал портфеля и в поток не входят.

**Доход и расход** с чек-инов (`snapshot.income` / `expense`) **не** входят в расчёт прироста: они относятся к оперативным счетам. Деньги попадают в портфель роста только после перевода на фонд/вклад/инвестиции.

Знак потока: **плюс** = капитал в портфель пришёл, **минус** = ушёл.

Если перевод произошёл между датами чек-инов, он относится к интервалу, который заканчивается ближайшим следующим чек-ином.

---

## 3. Абсолютный прирост

Для периода от даты первого чек-ина `t₀` до последнего `t₁`:

```
прирост = капитал(t₁) − капитал(t₀) − Σ потоков за (t₀, t₁]
```

Пополнения переводом **не входят** в прирост: они вычитаются как потоки. Доход/расход чек-ина игнорируются.

Виджет «Пополнения» на дашборде показывает `Σ потоков` (чистый капитал, вошедший в фонд/вклад/инвестиции переводами).

---

## 4. Процент прироста (Modified Dietz)

Простое деление `прирост ÷ капитал(t₀)` завышает % если пополнение было в середине периода: деньги работали не всё время.

Поэтому знаменатель — **взвешенный капитал**:

```
T = число календарных дней от t₀ до t₁
для каждого потока i на дате dᵢ:
  вес_i = (T − дней_от_t₀_до_dᵢ) / T     # доля периода после поступления
взвеш.капитал = капитал(t₀) + Σ (поток_i × вес_i)

прирост% = прирост / взвеш.капитал
```

Смысл веса: пополнение в первый день периода почти полностью входит в базу; пополнение в последний день имеет вес ≈ 0 (на него ещё не успели «накапать» проценты в этом периоде).

Если `взвеш.капитал = 0`, процент не определён (`null` / «—»).

### Пример

- 1 янв: вклад 100 000  
- 16 янв: перевод с оперативного +50 000  
- 31 янв: вклад 151 000  

```
прирост = 151 000 − 100 000 − 50 000 = 1 000
T = 30, дата потока — день 15 → вес = 15/30 = 0,5
взвеш.капитал = 100 000 + 50 000 × 0,5 = 125 000
прирост% = 1 000 / 125 000 = 0,8%
```

---

## 5. Годовые

Из процента за период длиной `N` дней:

```
годовых = (1 + прирост%) ^ (365 / N) − 1
```

Для **помесячной** строки дополнительно:

```
годовых_из_месяца = (1 + прирост%_месяца) ^ 12 − 1
```

Помесячный ряд: закрытие месяца = последний чек-ин месяца; открытие = закрытие предыдущего месяца (для первого месяца — первый чек-ин этого месяца). На каждом месяце тот же Modified Dietz.

## 8. Разложение прироста: валюта vs курс

В расшифровке **«Прирост»** на дашборде прирост портфеля роста раскладывается на два слагаемых (по каждому учитываемому счёту, затем сумма):

```
прирост_в_валюте = (остаток_конец − остаток_начало − переводы)   # в валюте счёта
заработано       = прирост_в_валюте × курс_на_конец_периода
курсовой_эффект  = остаток_начало × (курс_конец − курс_начало)   # 0 для базовой валюты
```

Сумма `заработано + курсовой_эффект` совпадает с **приростом в базе** (`accountGrowthBase`), если переводов не было. При переводах в иностранной валюте возможен небольшой остаток **«Даты переводов»**: переводы конвертируются по курсу на дату перевода, а слагаемое «заработано» — по курсу на конец периода.

Код: [`src/lib/growthFxBreakdown.ts`](src/lib/growthFxBreakdown.ts).

## 7. Краткая формула

```
капитал        = Σ остатков (фонд + вклад + инвестиции) в базе
поток          = переводы в/из портфеля роста (доход/расход чек-ина не входят)
прирост        = капитал_конец − капитал_начало − поток
взвеш.капитал  = капитал_начало + Σ(поток_i × доля_оставшихся_дней)
прирост%       = прирост ÷ взвеш.капитал
годовых        = (1 + прирост%)^(365/N) − 1

годовых_от_массы:
  числитель    = прирост фонда/вклада/инвестиций (без пополнений)
  знаменатель  = вся сумма денег на начало (все счета)
  прирост%     = числитель ÷ знаменатель
  годовых      = (1 + прирост%)^(365/N) − 1
```
