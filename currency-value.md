# Стоимость валютных счетов

Алгоритм вкладки **Валюты**: динамика эквивалента **только иностранных** валют в базовой валюте кошелька. Базовая валюта (например RUB) в график, виджеты и таблицу **не** входит.

Метрика сверху называется **курсовая разница** (абсолютная и относительная): изменение рыночного эквивалента валютной позиции.

## 1. Какие счета берутся

На каждую дату чек-ина:

1. Берутся все **неархивные** счета **любого вида** (фонд, вклад, инвестиции, оперативный, наличка, кредитка).
2. Отфильтровываются счета в **базовой** валюте (`settings.baseCurrency`).
3. Оставшиеся группируются по коду валюты (USD, EUR, …).

Базовая валюта не участвует ни в сумме, ни в долях, ни в курсовой разнице на этой вкладке.

На дашборде колонка «Прирост» по-прежнему считает только фонд/вклад/инвестиции; на вкладке Валюты — **все** иностранные счета (`allKindsGrowth`).

## 2. Эквивалент на дату

Для валюты `C` на дате `d`:

```
эквивалент(C, d) = Σ  toBase(остаток_счёта, C → база, курс_на_d)
```

Курс — из кэша ЦБ на дату `d` (или ближайший доступный pivot), иначе ручные курсы настроек.

Точка графика = `{ date: d, values: { USD: …, EUR: … } }` — каждая серия уже в базовой валюте.

---

## 3. Виджеты: курсовая разница

По серии точек от первой до последней даты чек-ина:

```
start = Σ values всех иностранных валют на первой дате
end   = Σ values всех иностранных валют на последней дате

курсовая разница     = end − start
курсовая разница %   = (end − start) / start   (если start ≠ 0)
```

В эти величины входят **и** изменение количества валюты, **и** изменение курса. Это не Modified Dietz портфеля роста — отдельная метрика валютной позиции.

Пример: 1000 USD, курс вырос на 1 ₽ → эквивалент +1000 ₽ при том же количестве долларов.

Разложение для расшифровки:

```
курсовой эффект     = Σ остаток_начало × (курс_конец − курс_начало)
изменение остатков  = Σ (остаток_конец − остаток_начало) × курс_конец
курсовая разница    = курсовой эффект + изменение остатков
```

---

## 5. Краткая формула

```
валюты     = уникальные коды счетов кроме baseCurrency (все виды)
V(C, d)    = Σ остатков в C, переведённых в базу по курсу d
итог(d)    = Σ_C V(C, d)
Δ абс.     = итог(последняя) − итог(первая)   // курсовая разница
Δ %        = Δ абс. / итог(первая)
```
