# Стоимость валютных счетов

Алгоритм вкладки **Валюты**: динамика эквивалента **только иностранных** валют в базовой валюте кошелька. Базовая валюта (например RUB) в график, виджеты и таблицу **не** входит.

- [`src/components/currencies/CurrenciesPanel.tsx`](src/components/currencies/CurrenciesPanel.tsx)
- [`src/components/currencies/CurrencyValueChart.tsx`](src/components/currencies/CurrencyValueChart.tsx)

---

## 1. Какие счета берутся

На каждую дату чек-ина:

1. Берутся все **неархивные** счета.
2. Отфильтровываются счета в **базовой** валюте (`settings.baseCurrency`).
3. Оставшиеся группируются по коду валюты (USD, EUR, …).

Базовая валюта не участвует ни в сумме, ни в долях, ни в приросте на этой вкладке.

---

## 2. Эквивалент на дату

Для валюты `C` на дате `d`:

```
эквивалент(C, d) = Σ  toBase(остаток_счёта, C → база, курс_на_d)
```

Курс — из кэша ЦБ на дату `d` (или ближайший доступный pivot), иначе ручные курсы настроек.

Точка графика = `{ date: d, values: { USD: …, EUR: … } }` — каждая серия уже в базовой валюте.

---

## 3. Виджеты сверху

По серии точек от первой до последней даты чек-ина:

```
start = Σ values всех иностранных валют на первой дате
end   = Σ values всех иностранных валют на последней дате

абсолютный прирост = end − start
относительный %    = (end − start) / start   (если start ≠ 0)
```

В эти величины входят **и** изменение количества валюты (например проценты по вкладу), **и** изменение курса. Отдельного вычитания доходов/расходов здесь нет: вкладка показывает изменение рыночного эквивалента валютной позиции.

Пример: 1000 USD, курс вырос на 1 ₽ → эквивалент +1000 ₽ при том же количестве долларов.

---

## 4. График и таблица

| Элемент | Содержание |
|---------|------------|
| График | Линии по каждой иностранной валюте (эквивалент в базе) |
| Таблица | Группы только по иностранным валютам; базовая — скрыта |
| Пустое состояние | Нет счетов ≠ базовой валюты |

На **дашборде** сводка по валютам по-прежнему показывает все валюты, включая базовую — это отдельный отчёт.

---

## 5. Краткая формула

```
валюты     = уникальные коды счетов кроме baseCurrency
V(C, d)    = Σ остатков в C, переведённых в базу по курсу d
итог(d)    = Σ_C V(C, d)
Δ абс.     = итог(последняя) − итог(первая)
Δ %        = Δ абс. / итог(первая)
```
